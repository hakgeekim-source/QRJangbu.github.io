# 큐알장부 - 안드로이드 앱 (PWA)

안드로이드 홈 화면에 **앱 아이콘**으로 설치되는 버전입니다.
설치 후에는 주소창 없이 **전체화면**으로 실행되고, **인터넷 없이도(오프라인)** 동작합니다.

## 구성 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 큐알장부 본체 (PWA 설정만 추가, 기능은 원본과 동일) |
| `manifest.webmanifest` | 앱 이름·아이콘·전체화면 설정 |
| `sw.js` | 오프라인 지원 |
| `icons/` | 프로그램 로고와 동일한 앱 아이콘 (192 / 512 / 적응형) |

## 왜 호스팅이 필요한가요?

안드로이드는 **HTTPS 주소**로 열린 웹앱만 앱으로 설치할 수 있습니다.
폴더를 한 번만 무료 호스팅에 올리면, 이후 폰에서는 주소 접속 → 설치만 하면 됩니다.
(설치 후에는 서버 없이 폰 안에서 동작합니다.)

## 1단계: 무료 호스팅에 올리기 (택 1)

**A. Netlify Drop (가장 쉬움, 가입 없이 가능)**
1. 브라우저에서 `app.netlify.com/drop` 접속
2. `QRJangbu_Android` **폴더 전체**를 화면에 드래그
3. 발급된 `https://xxxx.netlify.app` 주소를 복사

**B. GitHub Pages**
1. 새 저장소 생성 → 이 폴더의 파일을 모두 업로드
2. Settings → Pages → Branch: main 선택 → 발급된 주소 확인

**C. Cloudflare Pages** 등 정적 호스팅이면 모두 가능

> 주의: `index.html`이 폴더 맨 위에 오도록, 폴더 **안의 파일들**이 루트에 올라가야 합니다.

## 2단계: 폰에 설치

1. 안드로이드 **Chrome**으로 위 주소 접속
2. 메뉴(⋮) → **앱 설치** (또는 **홈 화면에 추가**)
3. 홈 화면에 **큐알장부** 아이콘이 생성됩니다
4. 아이콘으로 실행하면 전체화면 앱으로 열립니다

한 번 열어서 로딩이 끝나면 이후에는 비행기 모드에서도 실행됩니다.

## 기존 데이터 옮기기 (중요)

장부 데이터는 **사용 중인 앱/브라우저 안에 저장**됩니다. PC 버전이나 다른 브라우저의 데이터는 폰 앱에 보이지 않습니다.

1. 기존 화면에서 **백업**으로 파일 저장
2. 파일을 폰으로 전송 (카카오톡 나에게 보내기, 구글 드라이브, 메일 등)
3. 폰 앱에서 **복원**

폰 앱을 삭제하거나 Chrome 사이트 데이터를 지우면 장부도 사라지니, 주기적으로 백업하세요.

## 업데이트 방법

`index.html`을 수정해 다시 올린 뒤, `sw.js` 첫 줄 근처의
`const CACHE = 'qrjangbu-v1';` 를 `v2`, `v3` … 으로 올리면 폰이 새 버전을 받습니다.
(온라인 상태에서는 앱을 열 때 최신본을 우선 불러옵니다.)

## 문제 해결

| 증상 | 해결 |
|---|---|
| "앱 설치" 메뉴가 안 보임 | 주소가 `https://`인지 확인, Chrome 최신 버전 사용, 페이지를 한 번 새로고침 |
| "홈 화면에 추가"만 보임 | 바로가기로 추가돼 주소창이 보일 수 있음 → 폴더가 루트에 올라갔는지 확인 후 재설치 |
| 전체화면이 아님 | 삼성 인터넷 등 다른 브라우저는 일부 미지원 → Chrome 사용 |
| 아이콘이 예전 모양 | 앱 삭제 후 재설치 |
